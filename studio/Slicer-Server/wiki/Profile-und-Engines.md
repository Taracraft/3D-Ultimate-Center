# Profile und Engines

Der Quell-Preflight enthaelt keine Slicing-Engine. Fuer eine spaetere Betriebsinstallation benoetigt jede Engine eine dokumentierte Version, Herkunft, SHA-256-Pruefsummen, Laufzeitbibliotheken und anwendbare Lizenzhinweise.

Drucker-, Maschinen-, Prozess- und Filamentprofile muessen zur konkreten Engine und zum Druckermodell passen. Ein vorhandener Dateiname ist kein Funktionsnachweis. Mehrfarbenauftraege brauchen eindeutige Zuordnungen zu tatsaechlich verfuegbaren Materialkanaelen; eine einzelne externe Spule ersetzt keine Mehrmaterialbelegung.

Eigene Konfigurationen und Profile duerfen fuer die erlaubte private Nutzung angepasst werden. Das ist von Aenderungen am lizenzierten Programmquellcode getrennt. Fremde Profilpakete koennen eigene Nutzungsbedingungen haben.
