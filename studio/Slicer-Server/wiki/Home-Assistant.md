# Home Assistant verbinden

Ultimate 3D Studio wird als Integration eingerichtet. In den Optionen stehen ein externer Slicer und die Supervisor-Verwaltung als getrennte Wege zur Verfügung.

Für einen externen Server werden Adresse, Secret und ein vertrauenswürdiges TLS-Zertifikat benötigt. Die Zugangsdaten bleiben in Home Assistant; die Browseroberfläche erhält sie nicht.

Die Supervisor-Verwaltung prüft vorhandene Pakete und einen unterbrochenen Einrichtungszustand. Eine freigegebene App-Paketversion ist noch nicht hinterlegt. Details: [Einrichtungswege](../SUPERVISOR_APP_SETUP.md).
