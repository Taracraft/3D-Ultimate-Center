# Lizenz und Nutzung

Gewuenscht ist eine proprietaere, einsehbare Software fuer private, nichtkommerzielle Nutzung ohne Erlaubnis zur Aenderung des Programmquellcodes. Dies ist keine Open-Source-Lizenz. Der eigene Lizenztext steht in Slicer-Server/LICENSE.

Die neue Lizenz umfasst die dort beschriebenen neuen eigenen Dateien. Dokumentierte Einstellungen und eigene Modelle/Profile bleiben fuer private Nutzung anpassbar. Entwicklung durch den Rechteinhaber oder von ihm beauftragte Entwickler ist davon nicht ausgeschlossen.

Bestehende MIT-Rechte sowie Lizenzen von Engines, Betriebssystem, Python und Bibliotheken gelten weiter. Der erzeugte Worker-Payload wird durch das Verpacken nicht neu lizenziert. Der genaue Rechteumfang des spaeteren gesamten Releases ist noch zu pruefen; eine pauschale Umetikettierung waere falsch.

Auf GitHub koennen oeffentliche Repositorys nach den Plattformbedingungen angesehen und geforkt werden. Ein Aenderungsverbot kann keine technische Bearbeitungssperre fuer heruntergeladene Dateien herstellen. Vor Veroeffentlichung sind Lizenztext, Rechteinhaberschaft und konkrete Softwarekopplung rechtlich zu pruefen.
