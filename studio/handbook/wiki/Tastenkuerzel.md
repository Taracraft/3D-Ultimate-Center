# Tastenkürzel

| Eingabe | Aktion |
| --- | --- |
| Strg+Z | Rückgängig |
| Strg+Umschalt+Z | Wiederholen |
| Strg+C / Strg+X / Strg+V | Kopieren / Ausschneiden / Einfügen |
| Strg+A | Auswahl im aktuellen Kontext erweitern |
| Entf | Aktuelle Auswahl löschen |
| Strg+Klick / Umschalt+Klick | Mehrfachauswahl in der Objektliste |

In Textfeldern gelten die üblichen Texteingaben. Während laufender Vorgänge können einzelne Aktionen vorübergehend nicht verfügbar sein. Vor dem Löschen prüfen, ob Modelle oder Malbereiche ausgewählt sind.
