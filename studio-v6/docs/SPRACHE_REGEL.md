# Sprache / Language Regel

## Verbindliche Regelung (2026-09-20)

Alle Antworten an den Nutzer sind **ausschließlich auf Deutsch** zu verfassen.

### Geltungsbereich
- Nutzerinteraktion/Kommentare
- Commit-Nachrichten können Englisch sein (Konvention)
- Code-Kommentare können Englisch sein (Konvention)
- Dokumentation im Repo: Deutsch oder Englisch je nach Datei

### Verboten
- Chinesische Schriftzeichen in Antworten an den Nutzer
- Code-Snippets außer in technischen Artikeln

### Hintergrund
Der Nutzer arbeitet primär Deutsch. Jegliche andere Sprache (insbesondere Chinesisch) ist bei direkter Kommunikation zu unterlassen.

### Technische Prävention
Falls ein anderes Modell (z.B. chinesisches) involviert ist:
- Prompt explizit auf Deutsch setzen
- System-Hinweis in Memory/REGELN festhalten
